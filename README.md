A collection of handy scripts, configurations, and operational notes for running programming contests. **Work in progress.**

## Proposed Repository Structure

```text
utils/
├── docs/                    # System setup, operating procedures, and troubleshooting
├── ansible/
│   ├── inventories/         # Example inventories grouped by lab and machine role
│   ├── playbooks/           # Provisioning, checks, distribution, resets, and power management
│   ├── roles/               # Reusable configuration and administration tasks
│   └── templates/           # Configuration templates
├── scripts/
│   └── broccoli/            # Broccoli initialization, startup, and health checks
└── examples/                # Sanitized configuration examples; no real credentials
```
